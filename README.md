# Foundation Calculator

**Расчёт нагрузок и ширины подошвы фундамента · Python / Tkinter**

Небольшое настольное приложение с русскоязычным интерфейсом: ввод параметров здания, сбор нагрузок по осям Д, В и З и вычисление ширины подошвы фундамента.

## Возможности

- Учёт собственного веса стен и фундамента.
- Ввод нагрузок от перекрытий, снега и полезной нагрузки.
- Расчёт по трём осям с отдельной несущей способностью грунта для каждой.
- Локальная работа без сервера, аккаунтов и сетевых запросов.

## Запуск

Нужен Python 3 с поддержкой Tkinter. Сторонних Python-зависимостей нет.

```bash
python3 -m tkinter  # проверка доступности Tkinter
python3 min.py
```

В Linux модуль Tkinter может устанавливаться отдельно пакетом `python3-tk`. В Windows обычно доступна команда `python` вместо `python3`.

## Как пользоваться

1. Откройте форму кнопкой «Перейти к расчёту!».
2. Заполните геометрию, характеристики материалов и нагрузки.
3. Укажите положительную несущую способность грунта отдельно для каждой оси.
4. Нажмите «Рассчитать». Результаты появятся под формой.

## Устройство проекта

```text
min.py                 — интерфейс и расчётные функции
tests/test_width.py    — регрессия расчёта ширины
.github/workflows/     — автоматическая проверка в GitHub Actions
```

Интерфейс построен на стандартной библиотеке Tkinter. Приложение использует событийную модель: кнопки вызывают расчётные методы и обновляют результаты в окне.

## Статус и ограничения

Учебный прототип, демонстрирующий автоматизацию расчётов и работу с графическим интерфейсом. В исходной модели есть неоднозначности единиц измерения и состава нагрузок; перед практическим использованием необходимо проверить формулы, единицы и методику. Проект не заявляет соответствия строительным нормативам.

Возможные направления развития: единая система единиц, выделение расчётного ядра, проверка всех входных данных и адаптивная компоновка формы.

## Приватность

Приложение не сохраняет введённые значения в файлы и не отправляет их по сети. В репозиторий не должны попадать реальные расчёты, персональные данные, `.env`, ключи и локальные настройки — типовые файлы исключены через `.gitignore`.
